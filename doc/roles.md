# Market Roles

Who is responsible for what?

## 👷‍♂️️ Maintainers

The Axon Ivy Market is maintained by team-octopus.

Maintainers are responsible for:

- do the initial onboarding review
- select and present products on the market website
- [monitor](https://axonivy-market.github.io/market-monitor/) the stability of the Actions pipeline
  - suggest fixes; especially for builds that failed due to changes in the ivy engine or ivy-project-parent.
- migrate products to new Axon Ivy versions, with help from the code owner if needed
- help code owners align with the Market concepts

## 🧑‍💻️ Codeowners

The code owner is the main active contributor to an axonivy-market repository.
In most cases, it's the initial committer.

The code owner remains in charge of:

- review incoming PRs
  - help users to align to the concepts of the chosen solution
- engage with the community on incoming Issues
  - give feedback on requests
